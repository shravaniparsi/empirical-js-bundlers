# Excalidraw five-tool adapter acceptance

The pinned Excalidraw application now builds and passes the same production correctness contract with Vite, Rspack, esbuild, Webpack, and Rollup. GitHub Actions run [36818086629](https://github.com/shravaniparsi/empirical-js-bundlers/actions/runs/36818086629) passed all five matrix jobs at commit `11ba2abcc9b6b21010d5b3d24d2d826f9ae089df`. The shared output-validator change also passed the complete Memos five-tool regression in run [36817938228](https://github.com/shravaniparsi/empirical-js-bundlers/actions/runs/36817938228).

Every tool used Excalidraw commit `5db42c3ddbbdc44d10120ab2f18e0864d083e268`, whose 1,297 tracked files reverified to inventory hash `1645f0400e7c5ccbad50f0d8e5ba967df6bd06e3d26fe84b88aa7d119a4e8f01`. The tools shared one npm 11.9.0 lockfile (`19bf547fe73dbdaf89d4bcdaec103f8f58f1b4354d3cb301acdd256ca54cea05`), ten linked workspace packages, and the same two compatibility transforms. Those transforms expand the Vite-specific variable locale import into 57 literal lazy imports and replace PWA registration with a local no-op module; their resulting source hashes are recorded in every preparation receipt.

For every tool, the gate verified the native production build, JavaScript and external CSS, useful application source maps, and emitted WOFF2 assets. A Chrome session then verified loaded UI fonts, a visible canvas, rectangle drawing and movement, persistence after reload, and an actual downloaded SVG. All five sessions reported zero browser errors and zero unexpected external requests under the declared local fixtures. The complete downloaded workflow artifacts, including logs, source receipts, manifests, saved DOM, and screenshots, are retained in this directory with run metadata and a SHA-256 manifest.

This evidence completes the planned second independently selected real-world five-tool workload. It establishes adapter correctness and workload feasibility. It remains marked `publicationEligible: false` because it contains no comparative timing measurements. Publication-ready work still requires one final runtime choice and revalidation, real-world HMR acceptance, a frozen/preregistered sampling and analysis protocol, fresh randomized independent measurement sessions, and the resulting analysis and manuscript revision.

# Node 24 common-runtime revalidation

The confirmatory runtime is frozen at Node.js `24.14.0` in `profiles/runtime-v1/policy.json`. At the 2026-09-30 decision date, Node 24 (Krypton) was the active LTS line in the [Node.js Release Working Group schedule](https://github.com/nodejs/Release), with maintenance beginning 2026-10-20 and end of life scheduled for 2028-04-30. The exact patch is fixed to prevent runtime drift between correctness checks and later measurement sessions.

GitHub Actions run [36819476193](https://github.com/shravaniparsi/empirical-js-bundlers/actions/runs/36819476193) passed all 32 jobs at commit `20e864556785b485b721158a18bb31c3d773bc57`. Every job produced a passing runtime receipt for Node 24.14.0. The matrix covered 20 production-v1 synthetic cells (five tools across 200, 500, 2,000 and 5,000 modules), five Bulletproof React production cells, six development-v1 HMR cells (Vite, Rspack and Webpack at 200 and 5,000 modules), and the dependency/profile audit. All 25 production builds passed their output contracts and browser checks; all six HMR sessions passed three sequential edits, state persistence, reload detection, byte-exact source restoration and cleanup.

The first diagnostic run [36818992901](https://github.com/shravaniparsi/empirical-js-bundlers/actions/runs/36818992901) passed 31 of 32 jobs and exposed one packaging defect before Rspack/Bulletproof build execution. The old lock had been generated under `legacy-peer-deps=true`, so strict npm 11 rejected its omitted Webpack-compatible peer closure. The corrected lock was generated with npm 11.9.0 strict peer resolution, passed a clean-install check and the equal application-dependency audit, and then passed the complete Bulletproof scenario in the accepted run. The old and repaired lock hashes are retained in `acceptance.json`.

The Memos and Excalidraw five-tool suites had already passed on the same Node 24.14.0 runtime in runs [36817938228](https://github.com/shravaniparsi/empirical-js-bundlers/actions/runs/36817938228) and [36818086629](https://github.com/shravaniparsi/empirical-js-bundlers/actions/runs/36818086629). Together, the evidence closes the common-runtime correctness gate across the accepted synthetic, Bulletproof, Memos and Excalidraw profiles.

The GitHub annotation about Node 20 concerns the internal JavaScript runtime bundled with `actions/checkout@v4`, `actions/setup-node@v4` and `actions/upload-artifact@v4`. Each experiment job independently verified its active process runtime as Node 24.14.0. The complete downloaded evidence, including build/install logs, host receipts, production contracts, browser reports, HMR reports and run metadata, is archived here and covered by `SHA256SUMS.json`.

These are correctness runs, not performance observations. The next implementation gate is real-world HMR acceptance for the Memos and Excalidraw profiles, followed by the frozen sampling and analysis protocol and fresh randomized independent measurement sessions.

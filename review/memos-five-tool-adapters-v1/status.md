# Memos five-tool adapter acceptance

The pinned Memos application now builds and passes the same production correctness contract with Vite, Rspack, esbuild, Webpack, and Rollup. GitHub Actions run [36366232069](https://github.com/shravaniparsi/empirical-js-bundlers/actions/runs/36366232069) passed all five matrix jobs at commit `5aa3ab6d07158d88cfec92461e34e328ad009037`. The matching upstream Vite control passed in run [36366232074](https://github.com/shravaniparsi/empirical-js-bundlers/actions/runs/36366232074).

Each tool used the same 526-file application profile (`4154c76d327ba48d3b63e6b8b52b3918fee7194f85f75c64b45c70128b0c7a19`), exact dependency manifest, npm lockfile (`216d39db228d71434cb3dc9815922c2c18336de4283eca74f9cd9678044fbbb4`), Babel React Compiler transform, and Tailwind/PostCSS transform. The pinned upstream source is Memos commit `05a2c6db7a3e926c9142a635f42f7af0f078c81d`; all 1,307 source files reverified to inventory hash `ee000791a3c7735ed0065006d32851eb3dfe4b42afc3bfb1053895b95f6dc14a`.

For every tool, the gate verified the native production build, ES2022 parsing, external CSS, compiled Tailwind output, useful application source maps, a separate MapLibre worker asset, and absence of the development entry tag. It then compiled the original Go backend, created a real administrator account, entered content through the authenticated Home editor, created and edited a Markdown memo, reloaded the page, checked successful `CreateMemo` and `UpdateMemo` responses, shut down the backend, and read the exact edited value from SQLite.

This evidence establishes adapter correctness and workload feasibility. It is deliberately marked `publicationEligible: false` because it contains no comparative timing measurements. Publication-ready work still requires a preregistered measurement campaign on this profile, at least one additional independently selected real-world application, repeated randomized runs with thermal and background-load controls, and analysis that keeps these new results separate from the authoritative consolidated-v4 corpus until validation is complete.
